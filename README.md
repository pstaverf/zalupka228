# zalupka228

## Запуск

Python 3.10 или новее:

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python mines.py
```

При обновлении переносите вместе `mines.py`, `localization.py` и папку `locales/`. Словарь переводов загружается локально, без внешних сервисов. Текущие параметры запуска и настройки сохранены.

## Языки

В личном чате: `/settings` → «🌐 Язык». Доступны русский (`ru`), английский (`en`), украинский (`uk`) и казахский (`kk`). Выбор сохраняется в `bot_user_settings.language` и применяется сразу.

Локализация охватывает меню, кнопки, игровые экраны и справку, баланс и переводы, банк, P2P, чеки, промокоды, события, рефералов, подарки, задания, административные экраны, ошибки и уведомления. Личные уведомления переводятся на язык получателя.

Никнеймы, имена, комментарии и причины блокировок остаются в исходном виде. Названия валют, технические идентификаторы и команды не переводятся. В примерах используются поддерживаемые команды: `/transfer` для mCoin, `/send` для MP; прежние русские варианты сохранены.

Банк и P2P распознают операции по стабильным данным кнопок; для прежних текстовых сообщений сохранено распознавание заголовков на всех четырёх языках. Правила игр, коэффициенты, финансовые расчёты и SQL-запросы не изменены.

## Изменение переводов

Переводы находятся в `locales/messages.json`: русский фрагмент — ключ, `en`, `uk` и `kk` — его переводы. Нельзя удалять или изменять параметры вида `{0}`, `{1}`. Динамические значения подставляются после перевода, поэтому пользовательский текст не обрабатывается словарём.

После изменения словаря выполните тесты и перезапустите бота.

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m py_compile mines.py localization.py
.venv/bin/python tests/benchmark_performance.py --iterations 100
```

Тесты проверяют полноту словаря, HTML и параметры шаблонов, сохранение и переключение языка, игровые варианты и коэффициенты, валюты, банковские и P2P-ответы после смены языка, язык уведомлений и изоляцию параллельных обработчиков. Для тестов используются временные базы SQLite и подменённые обращения к Telegram; настоящие платежи и сообщения не отправляются.
